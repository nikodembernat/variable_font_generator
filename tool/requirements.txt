# own. These are here so that the tests are not only checking the generator
# against itself: fontTools parses the font, FreeType rasterises it, resvg
# rasterises the source artwork, HarfBuzz shapes text with it, and the
# OpenType Sanitizer decides whether a browser would accept it.
