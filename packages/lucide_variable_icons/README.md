# lucide_variable_icons

45 [Lucide](https://lucide.dev) icons as a single **variable** OpenType font,
with Flutter bindings.

This package is generated by
[`variable_font_generator`](../variable_font_generator) and checked in so that
its golden tests have something to render. It is not published; it exists to
demonstrate the generator's output and to hold the tests that prove the
variation axes reach the Flutter engine.

## Use

```dart
import 'package:lucide_variable_icons/lucide_variable_icons.dart';

Icon(LucideIcons.house)
Icon(LucideIcons.house, size: 32, fill: 1)
Icon(LucideIcons.battery, weight: 700, grade: 100)

// Or set them for a whole subtree:
IconTheme(
  data: const IconThemeData(size: 32, fill: 1, weight: 500),
  child: const Icon(LucideIcons.star),
)
```

| axis | `Icon` parameter | range | default |
| ---- | ---------------- | ----- | ------- |
| `FILL` | `fill` | 0 – 1 | 0 |
| `wght` | `weight` | 100 – 700 | 400 |
| `GRAD` | `grade` | -50 – 200 | 0 |
| `opsz` | `opticalSize` | 20 – 48 | 24 |

A value outside a range is clamped by the renderer rather than rejected.

`lucide_variable_icons_index.dart` lists every icon by name, for browsing or
searching. Importing it keeps every icon in a release build — naming them all is
exactly what stops Flutter's tree shaker dropping any — so import it only where
you need to enumerate the set.

## Regenerating

```sh
./tool/generate_lucide_package.sh          # from the repository root
cd packages/lucide_variable_icons
flutter test --update-goldens              # only after looking at what changed
```
